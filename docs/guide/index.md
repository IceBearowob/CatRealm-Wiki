# 貓域圖鑑 (Guide)

歡迎來到貓域伺服器的**圖鑑系統**！本系統收錄伺服器中所有的自訂生物、素材、食譜、附魔突破、飾品、玩偶與空島世界。

將滑鼠懸浮在選單上的各個圖鑑圖示上方可查看名稱，**點擊已開放的項目可進入對應的子圖鑑頁面**：

### 核心功能列（9 格）

| 圖示 | 項目名稱 | 功能說明 |
| :---: | :--- | :--- |

| <img src="/textures/item/menu/root/trail.png" width="22" style="image-rendering:pixelated;display:inline" /> | **足跡** | 離開領地時留下足跡，60 分鐘內可以傳送回到領地中心 |
| <img src="/textures/item/menu/root/land.png" width="22" style="image-rendering:pixelated;display:inline" /> | **領地** | 查看領地資訊、刪減或調整玩家權限／配置特殊保護功能 |
| <img src="/textures/item/menu/root/buff.png" width="22" style="image-rendering:pixelated;display:inline" /> | **輔助** | 永久夜視／顯示血量／靈魂出竅／整理背包等，免安裝模組即可使用 |

| <img src="/textures/item/menu/root/mail.png" width="22" style="image-rendering:pixelated;display:inline" /> | **信箱** | 寄送或接收含有貓幣／物品／指令附件的郵件，支援批量已讀與刪除 |
| <img src="/textures/item/menu/root/guide.png" width="22" style="image-rendering:pixelated;display:inline" /> | **[圖鑑](/guide/)** | 收集遇見的生物、拿到的素材與飾品，以及吃過的食譜、踏上的空島 |

### 底部資訊與快捷列（9 格）

| 圖示 | 項目名稱 | 功能說明 |
| :---: | :--- | :--- |
| <img src="/textures/item/menu/root/online.png" width="20" style="image-rendering:pixelated;display:inline" /> | **線上** | 顯示當前伺服器線上人數與玩家資訊 |
| <img src="/textures/item/menu/root/performance/green.png" width="20" style="image-rendering:pixelated;display:inline" /> | **性能** | 伺服器當前運行效能狀態（TPS / MSPT） |
| <img src="/textures/item/menu/root/ping/green.png" width="20" style="image-rendering:pixelated;display:inline" /> | **延遲** | 當前與伺服器的網路連線延遲（Ping） |
| <img src="/textures/item/menu/root/flight/unlimited.png" width="20" style="image-rendering:pixelated;display:inline" /> | **飛行** | 領地自由飛行剩餘體力（持有月卡享無限飛行體力） |
| <img src="/textures/item/menu/root/balance_pass.png" width="20" style="image-rendering:pixelated;display:inline" /> | **錢包 / 月卡** | 查看當前貓幣餘額與月卡剩餘時間 |
| <img src="/textures/item/menu/root/sign/off.png" width="20" style="image-rendering:pixelated;display:inline" /> | **簽到** | 每天簽到獲得獎勵 |
| <img src="/textures/item/menu/root/task/3.png" width="20" style="image-rendering:pixelated;display:inline" /> | **任務** | 完成每日任務獲得獎勵（數字代表待完成數量） |
| <img src="/textures/item/menu/root/soul_sighting_off.png" width="20" style="image-rendering:pixelated;display:inline" /> | **靈魂出竅** | 切換進入觀察者視角四處探索並預覽容器（`/soul`） |
| <img src="/textures/item/menu/root/organize_backpack.png" width="20" style="image-rendering:pixelated;display:inline" /> | **整理背包** | 快速排序整理背包或容器內所有物品（`/sort`） |

> [!TIP] 新手引導列說明
> 累計遊玩未滿 24 小時的新玩家，在核心功能列與底部資訊列之間會額外顯示綠色的「**知識指導**」與紫色的「**尋找陪玩**」橫條；累計遊玩滿 24 小時後該排會自動隱藏，之後可分別在「**更多**」與主選單的「**陪玩**」中找到。
